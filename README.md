Sunreach Bay is an open-world crime game in three.js, set in an original sunset-lit coastal city: steal cars out of live traffic, run five story missions and courier jobs for Odile, fight the Marina Crew, and shake off SBPD cruisers and the helicopter as your wanted stars climb. It runs offline from static files, with synthesised sound and two in-car radio stations.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

## Controls

| Key | Action |
| --- | --- |
| W A S D | Walk / drive |
| Mouse | Look (click the game to capture the mouse) |
| Shift | Sprint |
| Space | Jump / handbrake drift |
| F or E | Get in or out of a car (take one by force) |
| Left click / right click | Punch or shoot / aim |
| Q, 1 2 3, wheel | Switch weapon |
| R | Change radio station (in a car) |
| H / C / G | Horn / look back / siren in a police car |
| Esc or P | Pause, save and load |
